# 📸 RetroSnap Studio - Cute & Retro Photo Booth Web App

Aplikasi filter foto lucu dan aesthetic berbasis **100% browser lokal** (tanpa backend/server luar, menjaga privasi penuh). Dilengkapi bingkai kamera MacBook Photo Booth, iPhone Camera Viewfinder, Instagram/TikTok Reels, Y2K Digicam, Korean Life4Cut, dan Polaroid.

---

## ✨ Fitur Utama

### 1. 🖼️ Frame & Bingkai Ikonik
- **MacBook Photo Booth**: Jendela klasik macOS dengan tombol traffic light (🔴 🟡 🟢), judul custom, tema Silver/Dark, dan tombol shutter bulat merah.
- **iPhone Camera Viewfinder**: UI kamera iOS asli dengan box fokus kuning `[  ]`, slider matahari, zoom badge (`0.5x`, `1x`, `2x`, `3x`), grid 3x3, mode kamera (*PHOTO*, *PORTRAIT*, dll), serta **Fitur Atur Skala Frame (50% - 150%)** untuk memperkecil atau memperbesar bingkai UI kamera sesuai selera.
- **Instagram / TikTok Reels**: Tampilan reels vertikal 9:16, tombol Like custom (misal `348K`), bubble komentar, piringan piringan hitam berputar, `@username`, caption, dan ticker lagu.
- **Y2K Digicam 2000s**: Tampilan LCD kamera jadul Cybershot, tanggal & jam digital warna oranye, indikator baterai hijau, dan tombol `REC` berkedip merah.
- **Korean Life4Cut (인생네컷 / Haru Film)**: Bingkai photobooth pastel Korea dengan stempel lucu dan pilihan warna background (*Baby Pink, Lavender, Mint, Butter, Noir, Denim*).
- **Instax Polaroid**: Border polaroid klasik dengan selotip washi tape pastel dan tulisan tangan kustom.
- **Spotify Music Player**: Kartu pemutar musik lo-fi transparan dengan progress bar, nama artis, dan lagu favorit.
- **GameBoy Camera 1998**: Frame konsol retro Nintendo abu-abu/ungu dengan LED baterai.

### 2. 🎨 Filter & Efek Kamera
- **Mac Squeeze**: Distorsi lengkung cembung/cekung khas Photo Booth Mac.
- **Thermal Heatmap**: False-color sensor panas infrared ala MacBook.
- **Comic Book**: Efek cel-shading komik pop-art.
- **Warhol Pop Art**: 4 kuadran warna kontras ikonik Andy Warhol.
- **Y2K Flash Glow**: Efek flash kamera digital malam hari dengan soft skin diffusion.
- **Vintage 35mm Film**: Tone analog hangat dengan bocoran cahaya (*light leak*).
- **Pastel Dream**: Nuansa peach dan pink lembut ala anime.
- **Cyber Neon**: Duotone cyan & magenta futuristik.
- **B&W Film Noir**: Hitam putih dramatis dengan kontras tinggi.
- **VHS 90s Glitch**: Garis scanline tabung CRT dan chromatic RGB shift.

### 3. 🎀 Stiker Lucu & Doodle Interaktif
- Koleksi emoji lucu (✨, 💖, 🎀, 🌸, 🐰, 🐱, 🧸, 🍓, dll).
- Badge Y2K (*CUTE, ANGEL, PRINCESS, VIP, XOXO, SUPERSTAR*).
- Teks kustom dengan pilihan font tulisan tangan (*Caveat*), bubbly (*Fredoka*), atau pixel retro (*VT323*).
- Stiker dapat digeser langsung di atas foto, diubah ukurannya, diputar, atau dihapus.

### 4. 🔒 100% Metode Lokal Browser (Aman & Privat)
- **Tanpa Server / Cloud**: Semua pemrosesan foto menggunakan HTML5 Canvas langsung di RAM browser perangkat Anda.
- **Webcam Langsung**: Ambil foto selfie langsung dengan timer countdown 3 detik / 5 detik, flash kamera, dan efek suara.
- **Upload / Drag & Drop**: Tarik foto dari komputer langsung ke layar aplikasi.
- **Built-in Presets**: Dilengkapi 4 foto sampel lucu (*Mochi Cat, Sweet Bunny, Honey Bear, Cyber Girl*) untuk langsung dicoba.
- **Export Resolusi Tinggi & Salin ke Clipboard**: Unduh format PNG/JPG atau langsung salin gambar ke clipboard untuk dipaste ke WhatsApp/Instagram.

## 🚀 Cara Menjalankan

Aplikasi saat ini telah aktif di:
```bash
http://localhost:5173/
```

Untuk menjalankan kembali di lain waktu:
```bash
npm run dev
```

Untuk build produksi:
```bash
npm run build
```
